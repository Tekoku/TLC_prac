# 东方邪星章 练习器 TLC Practice Tool v0.1
集成在《东方邪星章（汉化版）游戏本体的练习器/A practice tool integrated into the game The Last Comer (Chinese version)。
包含：
- 注入式dll工具
- 启动练习器的bat文件
不包含：
- 游戏练习器脚本
- 游戏本体
## 功能
- 章节跳转
- 道中 / BOSS 快速重开
- BOSS 非符 / 符卡跳转
- 练习资源调整
- 正常全关 / EX 的 Q 键重开与回退
- 锁残 / 锁雷
## 使用方法
1. 下载包含完整练习器的游戏版本，链接见下一部分
2. 阅读文件内的使用说明，按指引启动练习器
